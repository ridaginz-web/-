# 🐾 Memorize: Time Photo Studio (Lu Guang & Cheng Xiaoshi)

> **GitHub Description (для поля About / Description репозитория):**
> `🐾 Моти-чибики Лу Гуан и Чэн Сяоши для SillyTavern: память по вкладкам (События, Отношения, Секреты), поиск с Флешбеком для персонажа и свой API ✨`

Минималистичное расширение долговременной памяти (**Категории фактов + Хроника глав + Флешбеки**) для **SillyTavern** с милыми безрамочными моти-чибиками **Лу Гуана 🐱** и **Чэн Сяоши 🐶** (*Link Click*).

---

## ✨ Основные возможности (v1.5.0)

- **Живые моти-чибики с колечком прогресса (SVG):** Лу Гуан и Чэн Сяоши асинхронно моргают, подсвечивают часы и камеру при активном флешбеке, мягко приглушаются при наборе текста на телефоне и показывают круговой прогресс до следующего авто-сжатия.
- **Отдельные вкладки прямо в верхней плашке:**
  - **⏳ События · 💞 Отношения · 🗝 Секреты · 📍 Сцена · 📖 Хроника** — нажимайте на нужную вкладку вверху и сразу смотрите её содержимое.
- **📸 3 режима «Флешбека» + фотовспышка:**
  - Нажмите на любой факт и выберите тон воспоминания: **💭 Мысль** (молча во взгляде/мыслях), **💬 Вслух** (персонаж сам поднимает тему в диалоге) или **⚡ Триггер** (острая эмоциональная вспышка/дежавю), либо запустите сразу кнопкой **«⚡ Вспомнить сейчас»**.
- **Бережное хранение Секретов и Отношений + метки `NEW`:**
  - Текущая **Сцена** обновляется под момент, а **Секреты** и **Отношения** защищены от случайной потери при выжимке. Новые и обновлённые факты помечаются золотым бейджем **`new`**.
- **📦 Перенос памяти в «Новый сезон» чата:**
  - Кнопка **«📦»** в шапке окна позволяет в 1 тап скопировать или скачать `.json`-слепок памяти и перенести весь канон, главы и факты в новый чистый чат (как полную замену или слияние).
- **🔑 Автоматический скролл-список моделей своего API:** список моделей подгружается сам сразу после ввода URL и ключа — с живым поиском и выбором касанием.

## 🚀 Установка в SillyTavern

1. Откройте **SillyTavern** → вкладка **Extensions** (иконка кубиков вверху).
2. Нажмите **Install Extension**.
3. Вставьте ссылку на репозиторий GitHub:
   ```text
   https://github.com/ridaginz-web/st-memorize
   ```
4. Нажмите **Install** — маскот и панель настроек появятся сразу.

---

## ⚙️ Настройка своего API (по желанию)

1. Откройте **Extensions → 🐾 Memorize: Лу Гуан и Чэн Сяоши**.
2. Включите галочку **«🔑 Свой API с ключом»**.
3. Укажите:
   - **API Base URL**, например: `https://openrouter.ai/api/v1` или `https://api.deepseek.com/v1`
   - **API Key**: ваш ключ `sk-...`
   - Список моделей загрузится автоматически (или нажмите **«🔄 Обновить»**) — выберите быструю модель для выжимки (например, `deepseek/deepseek-chat` или `openai/gpt-4o-mini`).

## 📁 Структура репозитория

- `manifest.json` — манифест и описание расширения для SillyTavern
- `index.js` — точка входа, плавающий виджет чибиков, окно памяти и события SillyTavern
- `memory-core.js` — хранилище чата, сборка промпта, выжимка фактов, JSON-парсер и свой API
- `settings-panel.js` — панель настроек расширения и авто-список моделей API
- `mascots.js` — векторные моти-чибики Лу Гуана и Чэн Сяоши (SVG)
- `style.css` — оформление виджета и модального фотоальбома в тёмно-синих и золотых тонах
- `README.md` — документация и инструкция по установке
- `LICENSE` — открытая лицензия MIT
