# 🐾 Memorize: Time Photo Studio (Lu Guang & Cheng Xiaoshi)

> **GitHub Description (для поля About / Description репозитория):**
> `🐾 Милые моти-чибики Лу Гуан и Чэн Сяоши для SillyTavern: минималистичная память фактов, хроника длинных чатов и авто-выбор моделей своего API ✨`

Минималистичное расширение долговременной памяти (**Хроника глав + Ключевые факты**) для **SillyTavern** с милыми безрамочными моти-чибиками **Лу Гуана 🐱** и **Чэн Сяоши 🐶** (*Link Click*).

---

## ✨ Основные возможности (v1.2)

- **Милые безрамочные моти-чибики (SVG):** компактный плавающий маскот с круглым счётчиком в углу (можно выбрать дуэт, только Лу Гуана или только Чэн Сяоши). Свободно перетаскивается пальцем и открывает чистую панель памяти по нажатию.
- **Минималистичный интерфейс без «каши»:** всего 2 аккуратные вкладки:
  - **Факты** — единый чистый список актуальных деталей без нагромождения категорий (закрепление `📌`, отключение `👁`, редактирование прямо в строке).
  - **Хроника** — пошаговые главы чата (`#1–20`, `#21–40`...) и сжатая основа сюжета.
- **Архитектура для больших чатов (100–500+ сообщений):**
  - Память гарантированно инжектится в промпт перед каждым ответом бота (`Depth = 2`), поэтому персонаж не забывает события 30 или 300 сообщений назад.
  - Старые главы автоматически сжимаются в **«Основу сюжета»**, удерживая объём памяти компактным (~350–650 токенов).
  - Кнопка **«⏪» (Откат Лу Гуана)** возвращает прошлое состояние памяти в один тап.
- **🔑 Автоматический скролл-список моделей своего API:** список моделей подгружается сам сразу после ввода URL и ключа — с живым поиском и выбором в одно касание.

## 🚀 Установка в SillyTavern

1. Откройте **SillyTavern** → вкладка **Extensions** (иконка кубиков вверху).
2. Нажмите **Install Extension**.
3. Вставьте ссылку на ваш репозиторий GitHub:
   ```text
   https://github.com/ridaginz-web/st-memorize
   ```
4. Нажмите **Install** и перезагрузите страницу при необходимости.

---

## ⚙️ Настройка своего API (по желанию)

1. Откройте **Extensions → 📸 Memorize: Лу Гуан и Чэн Сяоши**.
2. Включите галочку **«🔑 Использовать свой API с ключом»**.
3. Укажите:
   - **API Base URL**, например: `https://openrouter.ai/api/v1` или `https://api.deepseek.com/v1`
   - **API Key**: ваш ключ `sk-...`
   - Нажмите **«🔌 Проверить ключ и загрузить модели»** и выберите быструю модель для выжимки (например, `deepseek/deepseek-chat` или `openai/gpt-4o-mini`).
