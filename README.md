# 📸 Memorize: Time Photo Studio (Lu Guang & Cheng Xiaoshi)

> **GitHub Description (для поля About / Description репозитория):**
> `📸 Чиби-хранители памяти Лу Гуан и Чэн Сяоши для SillyTavern: авто-выжимка сюжета (Summarize), альбом карточек фактов (Memory Book), откат снимков и свой API с ключом ✨`

Расширение долговременной памяти фактов (**Memory Book + Summarize**) для **SillyTavern** с интерактивным чиби-виджетом **Лу Гуана** и **Чэн Сяоши** в эстетике фотоателье «Время» (*Link Click*).

---

## ✨ Основные возможности

- **Чиби-хранители на экране (SVG):** перетаскиваемый виджет (поддерживает мышь и тач-экран на телефоне). Персонажи живые: отвечают репликами при нажатии, а при создании снимка памяти срабатывает анимация «хлопка» и золотое свечение глаз.
- **Гибрид Памяти Фактов и Сводки (Memory Book + Summarize):**
  - **📖 Сжатая сводка** — краткий пересказ происходящего в 3–5 предложениях без воды.
  - **⏳ События** — ключевые сюжетные повороты.
  - **💞 Отношения** — динамика чувств, доверия, конфликтов и обещаний.
  - **🗝️ Детали и улики** — важные предметы, лор, секреты, травмы.
  - **📍 Текущая сцена** — локация, обстановка и текущая цель персонажей.
- **Изолированная память на каждый чат:** все карточки сохраняются внутри `chatMetadata` конкретного чата и не перемешиваются между разными чатами или персонажами.
- **Защита и «Откат Лу Гуана»:**
  - Закрепляйте важные факты замочком (`🔒`), чтобы нейросеть не перезаписала их при следующем сжатии.
  - Отключайте временные факты (`👁️` / `🙈`) или редактируйте текст прямо на карточках.
  - Кнопка **«⏪ Откат Лу Гуана»** возвращает предыдущий слепок памяти в один клик, если модель неудачно сделала выжимку.
- **🔑 Подключение своего API с ключом:** можно указать отдельный OpenAI-совместимый эндпоинт (OpenRouter, DeepSeek, OpenAI, прокси) и ключ — он хранится только локально в `localStorage` браузера и не попадает в экспорт настроек SillyTavern.

## 🚀 Установка в SillyTavern

1. Откройте **SillyTavern** → вкладка **Extensions** (иконка кубиков вверху).
2. Нажмите **Install Extension**.
3. Вставьте ссылку на ваш репозиторий GitHub:
   ```text
   https://github.com/ridaginz-web/st-memorize
   ```
4. Нажмите **Install** и перезагрузите страницу при необходимости.

---

## ⚙️ Настройка своего API (по желанию)

1. Откройте **Extensions → 📸 Memorize: Лу Гуан и Чэн Сяоши**.
2. Включите галочку **«🔑 Использовать свой API с ключом»**.
3. Укажите:
   - **API Base URL**, например: `https://openrouter.ai/api/v1` или `https://api.deepseek.com/v1`
   - **API Key**: ваш ключ `sk-...`
   - Нажмите **«🔌 Проверить ключ и загрузить модели»** и выберите быструю модель для выжимки (например, `deepseek/deepseek-chat` или `openai/gpt-4o-mini`).
